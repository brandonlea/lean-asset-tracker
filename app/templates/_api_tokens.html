Try it

curl -H "Authorization: Bearer YOUR_TOKEN" \
  {{ base_url }}/api/v1/summary

Returns totals, what is offline, and what expires soon — one call, enough for a dashboard widget:

{
  "assets": { "total": 14, "online": 9, "offline": 2, "no_agent": 3 },
  "counts": { "warranty_expiring_60d": 1, "eol_180d": 0, "locations": 6 }
}

Other things it does

  • GET /api/v1/assets?offline=true — everything not answering
  • GET /api/v1/assets?warranty_before=2027-01-01 — expiring kit
  • POST /api/v1/assets — register a new machine from a provisioning script
  • POST /api/v1/assets/42/history — log a part swap from the terminal

Rate limit {{ 120 }} requests/minute per token. Archiving is supported; permanent deletion deliberately is not — the API should never be the easy way to destroy history.
