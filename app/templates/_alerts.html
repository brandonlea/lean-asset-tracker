What you will be told about

  • • Server offline — no agent contact for {{ th.offline_min }} minutes
  • • Disk filling — at {{ th.disk_warn }}%, urgently at {{ th.disk_crit }}%
  • • Memory — at {{ th.mem_warn }}%
  • • Warranty ending — 60 days out, then 14
  • • End of life — 180 days out, then 30

Each one is sent once, then held back for 12 hours (urgent) or 3 days — so a failing disk tells you today, not every five minutes. An offline server stops us nagging about its own stale disk and memory figures, because the only honest thing to report is that it is offline.
